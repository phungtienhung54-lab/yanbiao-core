## 二、测试方法与策略

### 2.1 精准补测策略
- 使用 `pytest --cov=<module> --cov-branch --cov-report=term-missing` 定位未覆盖的行与分支。
- 优先补充五类测试：**异常处理、边界条件、空数据、无效 ID、文件读写失败**。
- 对核心模块采用参数化测试（`@pytest.mark.parametrize`）批量覆盖分支。

### 2.2 外部依赖隔离
- 使用 `monkeypatch` 模拟 `PIFGuard` 等外部依赖，避免规则干扰测试结果。
- 使用 `tmp_path` 为每个测试提供独立临时存储目录，测试后自动清理。

### 2.3 CI/CD 自动化
- 接入 GitHub Actions，配置 Python 3.12 环境。
- 执行命令：
  ```bash
  pytest tests/ --cov=core --cov-branch --cov-fail-under=95
